# JMAF: Java Magic Annotations Framework

### A continuation of [LibraOmni](https://github.com/jackraidenph/LibraOmni-1.21.1) project, aiming to enhance Java annotations capabilities with:
#### 1) Annotation unfolding
#### 2) Custom validations
#### 3) Annotation processing tasks that involve compile-time code and resource generation, and don't clash with incremental pipelines

#### All of those at compile-time

#### Now in a form of a pure extensible Java framework, not tied to Minecraft
